# Codex App Manager v0.5.3-rc.1

> Windows x64 预发布修复版 / Windows x64 release candidate

## 中文

此版本包含对上游 issue [Wangnov/Codex-App-Manager#260](https://github.com/Wangnov/Codex-App-Manager/issues/260) 的修复。

### 修复内容

- 便携模式解压 MSIX 时，依据 `AppxBlockMap.xml` 恢复逻辑文件路径。
- 将 `%40oai`、`%40statsig`、`%24_StatsigGlobal.js` 等归档名称正确还原为 `@oai`、`@statsig`、`$_StatsigGlobal.js`。
- 恢复 Computer Use helper 对随包 Node.js 模块的正常解析。
- 拒绝非法百分号编码、路径穿越、Windows 非法名称、大小写碰撞、缺失文件以及大小不一致的载荷。
- 支持对已安装的同版本便携包执行修复安装。

### 验证

- 前端和 Rust CI 通过。
- Windows NSIS 安装包构建通过。
- 安装、首次启动、升级和卸载生命周期 smoke test 通过。
- 官方 Codex MSIX 的 x64 与 ARM64 逻辑路径恢复及 Computer Use Node 模块解析测试通过。

### 安装说明

下载 `Codex-App-Manager_0.5.3-rc.1_windows-x64-setup.exe` 后运行即可。本预发布包未配置商业 Authenticode 证书，Windows SmartScreen 可能显示“未知发布者”；请使用同页提供的 SHA-256 文件校验下载完整性。

## English

This release candidate contains the fix for upstream issue [Wangnov/Codex-App-Manager#260](https://github.com/Wangnov/Codex-App-Manager/issues/260).

### Fixes

- Reconstructs logical portable MSIX paths from `AppxBlockMap.xml`.
- Restores encoded archive names such as `%40oai`, `%40statsig`, and `%24_StatsigGlobal.js` to `@oai`, `@statsig`, and `$_StatsigGlobal.js`.
- Restores bundled Node.js module resolution required by the Computer Use helper.
- Rejects malformed escapes, traversal, Windows-invalid names, case-insensitive collisions, missing payloads, and size mismatches.
- Allows same-version repair of an existing managed portable installation.

### Validation

- Frontend and Rust CI passed.
- The Windows NSIS installer build passed.
- Packaged install, first launch, upgrade, and uninstall smoke tests passed.
- Real official Codex MSIX logical-path and Computer Use module-resolution tests passed on x64 and ARM64.

### Installation

Download and run `Codex-App-Manager_0.5.3-rc.1_windows-x64-setup.exe`. This release candidate is not signed with a commercial Authenticode certificate, so Windows SmartScreen may show an unknown-publisher warning. Use the accompanying SHA-256 file to verify download integrity.
